# زاویه ذهن (`@zavieh.penhann`) — استودیوی ابری موشن‌گرافیک

مخزن رسمی تولید خودکار ویدیوهای ریلز پیج اینستاگرام **زاویه ذهن (`@zavieh.penhann`)** با کیفیت استودیویی **`1080×1920`، نرخ `60fps` واقعی، انکودینگ `H.264 High Profile (-preset slow -crf 14)` و صدای استریو `48kHz / 320kbps`**.

تمام مراحل سنتز نریشن فارسی (Gemini TTS)، فشرده‌سازی هوشمند مکث‌ها، زمان‌بندی کلمه‌به‌کلمه (`faster-whisper medium`)، رسم برداری با درخشش دولایه (`Deep Glow Halation`) و رندر نهایی روی سرورهای ابری **GitHub Actions** انجام می‌شود.

---

## مستندات مرجع پروژه

1. **[کالبدشکافی دقیق لحن، سرعت صدا و تدوین رقیب (`@ensan.besham`)](docs/COMPETITOR_FORENSIC_ANALYSIS.md)**  
   آنالیز کمی و طیفی ویدیوهای میلیونی رقیب: نرخ کلمه بر دقیقه (`WPM`)، نسبت زمان کلام فعال (`93.8% Voiced Ratio`)، فرکانس پایه صدا (`F0`)، ریتم برش‌های بصری (`هر ۳.۷ ثانیه`) و تفاوت هویت «زاویه ذهن».
2. **[راهنمای لحن، صدا و فرمول سناریونویسی (`Voice & Script Bible`)](docs/VOICE_TONE_AND_SCRIPT_BIBLE.md)**  
   تنظیمات دقیق صدای باریتون `Iapetus` جمینای، کالیبراسیون فرکانس حنجره با `Rubberband`، حذف خودکار سکوت‌های مرده (`190ms`)، حفظ مکث دراماتیک (`720ms`) و دستور زبان محاوره‌ای تهرانی.
3. **[مشخصات فنی پایپلاین رندر ۶۰ فریم (`Render Pipeline Spec`)](docs/RENDER_PIPELINE_SPEC.md)**  
   معماری موتور برداری `Cairo + Pillow Raqm RTL`، سینک قفل‌شده بر اساس ایندکس کلمات (`Word-Index Choreography`) و تنظیمات مسترینگ صدا و تصویر.

## نحوه اجرای رندر ابری در GitHub Actions

1. کلید API جمینای در بخش `Settings -> Secrets and variables -> Actions` با نام `GEMINI_API_KEY` به‌صورت رمزنگاری‌شده ذخیره شده است.
2. با هر `push` روی شاخه `main` یا از تب **Actions -> Render Zavieh Zehn Reel (60fps Studio) -> Run workflow**، سرور ابری گیت‌هاب کل پایپلاین را اجرا کرده و فایل `.mp4` نهایی + برگه‌ی کنترل کیفیت فریم‌ها (`QA Contact Sheet`) را هم به صورت **Artifact** و هم در بخش **Releases** منتشر می‌کند.
