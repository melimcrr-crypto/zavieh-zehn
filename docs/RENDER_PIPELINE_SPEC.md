# مشخصات فنی پایپ‌لاین رندر ابری ۶۰ فریم — زاویه ذهن (`@zavieh.penhann`)

## ۱. معماری زیرنویس تک‌بیت‌مپ تراز و ابریشمی (`render_core.py`)
- **تراز مطلق (`0.000px Jitter`):** کل عبارت به‌صورت یک رشته‌ی واحد RTL با `HarfBuzz/Raqm` شکل‌دهی شده و با `font.getmetrics()` روی خط کرسی ثابت `y = 1642.0` قفل می‌شود.
- **مسک گرادیانی پیوسته‌ی راست‌به‌چپ (`60fps Liquid Wipe`):** ترکیب برداری دو آرایه‌ی هم‌مختصات (`rgb(70,70,76)` خاکستری مات و `#FFFFFF` سفید درخشان با بلوم ملایم) توسط رمپ خطی `64px` منطبق بر `(t_start, t_end)` کلمات `faster-whisper (medium)`.

## ۲. معماری گرافیک برداری و حرکت دوربین
- بوم `#000000` اولد با دولایه‌ی مجزای `surf_sharp` و `surf_glow` (بلوم دوگانه‌ی گاوسی).
- رسم تدریجی مسیرها (`set_stroke_draw`)، فیزیک فنری (`spring_pop`)، زوم و پن پیوسته‌ی دوربین در ۶۰ فریم‌برثانیه، فیگورهای انسانی هندسی، خط آسمان تهران (`برج میلاد` + `برج آزادی` + البرز)، پنجره‌های پوشه‌ای با عرض تب داینامیک، مهرهای دوخطی زاویه‌دار و مخروط‌های نور.

## ۳. پروفایل انکودینگ مستر در GitHub Actions
- رندر موازی چندنخی (`multiprocessing.Pool`) روی تمام هسته‌های پردازنده‌ی سرور گیت‌هاب.
- خروجی تصویر: `1080×1920` • `60fps` • `H.264 High@L4.2` • `-preset slow -crf 14` • `bt709`.
- خروجی صدا: `AAC 320kbps @ 48,000 Hz Stereo` + `+faststart`.
